# Админка товаров

Веб-приложение на Google Apps Script. Сотрудницы открывают его с телефона по ссылке и заводят товары:
поля формы записываются в лист «Товары», фото — в папку товара на Google Диске. Сайт подхватывает изменения
при ежечасной сборке.

- `Code.js` — серверная часть: чтение и запись таблицы, проверка полей, фото на Диске.
- `Index.html` — экраны: список товаров и карточка товара.
- `appsscript.json` — настройки проекта: права, сервис Drive API, режим веб-приложения.

## Что умеет

- Список товаров с поиском и фильтрами «Без фото» и «Скрытые».
- Карточка товара. Комната, стиль, тип и наличие выбираются из листа «Справочники».
  Артикул нового товара назначается сам (следующий `KM-NNN`). Размеры проверяются так же, как при сборке сайта:
  все три или ни одного. «Сочетается с» заполняется поиском по товарам.
  Артикул поставщика и поставщик пишутся в таблицу, на сайт они не попадают.
- Фото. Перед загрузкой фото сжимается на телефоне до 2000 px. Главное фото отмечается звёздочкой,
  порядок меняется стрелками, удалённое фото уходит в корзину Диска. Файлы называются по порядку:
  `KM-001_01.jpg`, `KM-001_02.jpg`…
- «Показывать на сайте». Если выключить, в таблице появится «Нет» в столбце «На сайте», и товар исчезнет с сайта.
  Строка и фото при этом остаются. Столбец админка добавит сама при первом сохранении.
- При сохранении в «Дату проверки цены и наличия» записывается сегодняшнее число. Другие столбцы
  (например, «Актуальность») админка не трогает. Формулы в новой строке копирует из строки выше.

## Установка (один раз)

1. На Google Диске создайте папку для фото, например «Комод — фото». Внутри появятся папки товаров,
   названные артикулами: их создаёт админка. ID папки — последняя часть её адреса
   `drive.google.com/drive/folders/<ID>`.
2. Откройте таблицу каталога → «Расширения» → «Apps Script».
3. В редакторе: «Настройки проекта» (шестерёнка) → включите «Показывать файл манифеста appsscript.json».
4. Перенесите три файла: содержимое `Code.js` вставьте в `Code.gs`, создайте HTML-файл `Index`
   и вставьте `Index.html`, замените содержимое `appsscript.json`.
   Или через [clasp](https://github.com/google/clasp): `clasp clone <ID скрипта>` в папке `admin`, затем `clasp push`.
5. Папка с фото задана в `Code.js` (`DEFAULT_PHOTOS_FOLDER_ID`). Чтобы сменить её без правки кода:
   «Настройки проекта» → «Свойства скрипта» → `PHOTOS_FOLDER_ID` с ID новой папки.
6. «Начать развертывание» → «Новое развертывание» → тип «Веб-приложение».
   Выполнять как: «Пользователь, открывающий приложение». Доступ: «Все, у кого есть аккаунт Google».
   Скопируйте ссылку на приложение.
7. Откройте ссылку сами и разрешите доступ. Если в браузере вошли в несколько аккаунтов Google и видите
   «Не удалось открыть файл», откройте ссылку в окне инкогнито, войдя только в аккаунт салона. Google предупредит, что приложение не проверено:
   «Дополнительные настройки» → «Перейти на страницу…». Это ваше собственное приложение.

## Доступ сотрудниц

Админка работает от имени того, кто её открыл, поэтому права выдаются обычным «Поделиться»:

- таблицу каталога — «Редактор»;
- папку с фото — «Редактор».

Кто не получил доступ, увидит ошибку вместо списка товаров. Каждой сотруднице нужен свой аккаунт Google.
При первом входе она тоже один раз разрешает доступ, как в шаге 7. Ссылку удобно добавить на экран «Домой».
